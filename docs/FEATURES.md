# 📋 구현 기능 명세서 (Functional Specifications)

본 문서는 **캠퍼스 멀티 보드 시스템**에 구현된 세부 기능 명세와 비즈니스 규칙을 정리한 문서입니다.

---

## 1. 3단계 진화 모드 제어 기능

| 모드 | 명칭 | 화면 노출 요소 | 주요 동작 규칙 |
|---|---|---|---|
| **Step 1** | **단순 게시판** | 단일 게시판(자유게시판), 글쓰기, 검색 | 공간 선택기 및 다중 탭이 숨겨지며, 단 1개의 게시판에서 게시글 CRUD 및 작성자 권한을 검증합니다. |
| **Step 2** | **다중 게시판** | 게시판 탭 바, 관리자 [+ 새 게시판 개설] | 공간 내에 여러 목적별 게시판(공지, 자유, Q&A, 스터디)을 분류하고, 각 게시판마다 쓰기 권한과 공지 전용 여부를 개별 통제합니다. |
| **Step 3** | **복합 다중 게시판** | 공간 선택기 (Multi-Tenant Space Bar) | 학부/단과대별 독립 공간을 운영하며, 비인가 사용자의 공간 접근을 차단하는 **Tenant Isolation**이 활성화됩니다. |

## 2. 역할별 권한 및 시뮬레이션 기능

상단의 빠른 사용자 전환 바를 통해 다음 6개의 페르소나를 즉시 시뮬레이션할 수 있습니다:

### 1) 김철수 (컴퓨터공학부 학생)
- **소속 공간**: 컴퓨터공학부 공간, 캠퍼스 중앙광장
- **권한 범위**:
  - 인가된 공간의 게시글/댓글 조회, 검색, 좋아요
  - 일반 게시글 및 댓글 작성
  - **작성자 권한**: 본인이 작성한 글과 댓글만 수정 및 삭제 가능 (타인의 글은 수정/삭제 버튼 비활성화)
  - **공지사항 등록 불가**: 공지사항 체크박스 비활성화

### 2) 이영희 (컴퓨터공학부 과대표)
- **소속 공간**: 컴퓨터공학부 공간, 캠퍼스 중앙광장
- **권한 범위**:
  - 학생의 모든 기본 권한 보유
  - **공지사항 등록 권한**: 글 작성 시 `상단 고정 공지사항으로 등록` 토글 활성화
  - 공지 전용 게시판(학과 공지사항) 작성 권한 보유

### 3) 박교수 (컴퓨터공학부 교수)
- **소속 공간**: 컴퓨터공학부 공간, 캠퍼스 중앙광장
- **권한 범위**:
  - 학과 공식 교수 공지사항 등록
  - 학생들의 질문(Q&A)에 교수 자격 댓글 작성
  - 공지사항 고정 권한 보유

### 4) 최지원 (학교 관련 부서 관리자 / 소프 행정실)
- **소속 공간**: 컴퓨터공학부, 경영대학, 중앙광장 관리자
- **권한 범위**:
  - **게시판 관리**: 새 게시판 개설, 게시판 성격(공지 전용 여부) 및 쓰기 권한 지정
  - **AI 부적절물 심사**: AI가 자동 숨김 처리한 게시글 목록을 열람하고 `[다시 공개로 전환(승인 복원)]` 또는 `[영구 삭제]` 조치
  - 게시판 내 부적절한 글/댓글 강제 삭제 권한

### 5) 정민수 (경영대학 학생)
- **소속 공간**: 경영대학 공간, 캠퍼스 중앙광장
- **특화 테스트 시나리오**:
  - 경영대 소속으로, 컴퓨터공학부 공간 클릭 시 **`Tenant Access Denied` (접근 차단)** 경고 발생
  - 공간 간 데이터 격리 정책을 시각적으로 검증하는 테스트 계정

### 6) 총괄운영자 (대학본부 정보전산원)
- **소속 공간**: 전체 공간 슈퍼 어드민
- **권한 범위**: 시스템 내 모든 공간, 게시판, 게시물, 댓글, 모더레이션 로그에 대한 전권 보유

## 3. AI 유해 콘텐츠 자동 모더레이션 엔진

### 3.1 탐지 대상 및 가중치
- **심각한 비속어/욕설**: 95점 (즉시 숨김)
- **사기/도박/불법 광고 스팸**: 98점 (즉시 숨김)
- **학사 부정행위(족보 판매, 답안지 유출, 대리시험)**: 88점 (즉시 숨김)
- **폭력 및 위협성 발언**: 99점 (즉시 숨김)
- **타인 모욕 및 비하 표현**: 75점 (즉시 숨김)

### 3.2 Human-in-the-Loop 워크플로우
1. 사용자가 글 작성 중 유해 단어를 입력하면 실시간으로 감지 배너가 표시됩니다.
2. 유해 단어가 포함된 상태로 등록하면 일반 사용자 피드에서는 차단되고, 작성자 본인과 관리자에게만 경고 배지(`hidden_by_ai`)와 함께 표시됩니다.
3. 관리자는 **[AI 모더레이션 센터]**에서 다음의 2대 조치를 취할 수 있습니다:
   - **`다시 공개로 전환 (승인 복원)`**: `status`를 `active`로 변경하여 모든 학우에게 노출
   - **`영구 삭제 처리`**: 데이터베이스에서 즉시 제거
4. 모든 판정 내역은 **조치 이력 (Audit Logs)**에 처리 일시, 처리자 이름, 판정 결과와 함께 영구 보존됩니다.

## 4. 일반 사용자 편의 기능

- **실시간 검색**: 제목, 본문, 작성자명을 통합 검색
- **필터링**: 전체 글 / 공지사항만 보기 / 내가 작성한 글 모아보기
- **정렬 옵션**: 최신순 / 조회수순 / 좋아요순
- **상세 모달**: 게시글 열람 시 조회수 자동 증가, 원클릭 좋아요 토글, 실시간 댓글 등록/삭제
