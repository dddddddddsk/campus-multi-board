# 🤖 프롬프트 및 에이전트 인터랙션 기록 (Prompt & Agent Interaction Log)

본 문서는 **캠퍼스 멀티 보드 시스템** 개발 과정에서 사용된 사용자 요청 프롬프트, AI 에이전트의 분석 및 설계 의사결정, 단계별 구현 응답을 시간 순서대로 기록한 개발 로그입니다.

---

## 1. 초기 시스템 설계 및 개발 요청

### 📩 사용자 요청 (User Prompt 1)
```text
저번에 만든 게시판 체계를 바탕으로 게시판을 하나 더 만들거야.
- 단순 게시판
게시판 1개. 게시글과 회원 관리, 작성자 권한

- 다중 게시판
여러 게시판, 게시판 추가와 권한 관리, 게시판 구분

- 복합 다중 게시판
공간별 여러 게시판, 공간별 게시판과 사용자 관리, 공간 간 접근 차단

게시판을 하나 만들어, 그리고 여러 게시판을 관리하도록 확장해. 마지막으로 여러 운영자가 각자의 공간을 관리하도록 확장해.

서비스 대상 사용자: 학생 게시판

게시글을 읽는 사람: 학생, 교수

게시글이나 댓글을 작성하는 사람: 학생, 교수

공지사항을 등록하는 사람: 교수, 과대

부적절한 게시물을 관리하는 사람: 게시판에 부적절한 게시물을 숨김 처리하는 AI가 존재. 관리자가 숨김 처리 게시물을 다시 확인하여 삭제처리 하거나 다시 공개로 전환함.

게시판이나 운영 공간을 관리하는 사람: 학교 관련 부서 사람
---------------------------------------------
일반 사용자: 필요한 게시글을 쉽게 찾고 읽을 수 있어야 한다. 자신의 게시글과 댓글을 관리할 수 있어야 한다.
관리자: 게시판이 목적에 맞게 운영되도록 관리할 수 있어야 한다, 문제가 발생했을 때 대응할 수 있어야 한다.
```

### 🧠 에이전트 분석 및 의사결정 (Agent Internal Reasoning)
1. **기존 프로젝트 분석**:
   - 이전 작업 폴더(`complaint-board`)를 조회하여 기술 스택(React 19, Vite, Tailwind CSS, TypeScript, Lucide Icons)을 확인하고 동일한 최신 표준 환경을 계승하기로 결정.
2. **요구사항 분해 및 아키텍처 수립**:
   - **단순 게시판 (Step 1)**: 단 1개의 게시판에서 학생/교수 게시글 CRUD 및 작성자 본인만 수정/삭제 권한 검증.
   - **다중 게시판 (Step 2)**: 공지사항, 자유게시판, Q&A 등 목적별 다중 탭 분리 및 관리자의 게시판 동적 개설/권한 설정.
   - **복합 다중 게시판 (Step 3)**: 컴퓨터공학부, 경영대학, 중앙광장 등 공간(Tenant) 분리 및 비인가자의 접근을 원천 차단하는 `Tenant Isolation` 정책 구현.
   - **AI 모더레이션 엔진**: 한국어 비속어, 사기/스팸, 학사부정행위를 정밀 감지하는 `analyzeContentWithAI` 모듈 구현 및 관리자가 승인(복원)/영구삭제를 판정하는 `Human-in-the-Loop` 센터 설계.
   - **원클릭 페르소나 시뮬레이션**: 학생, 과대, 교수, 부서 관리자, 타과 학생, 총괄 관리자 6인을 상단 바에서 즉시 전환하여 권한을 테스트할 수 있도록 기획.
3. **구현 및 검증**:
   - `npm.cmd install` 및 프로젝트 구성 파일 작성.
   - `npm.cmd run build` 수행 결과: `644ms` 만에 타입 오류 없이 프로덕션 번들 생성 완료.

### 📤 에이전트 1차 응답 요약 (Agent Response 1)
- 3단계 발전형 아키텍처 다이어그램 및 설계 구조 설명 제공
- 6인 역할 및 권한 매트릭스(R&R) 명시
- AI 유해 콘텐츠 2단계 방어 체계 설명
- 멀티 테넌트 공간 간 접근 차단 정책 안내
- 로컬 실행 명령어(`npm.cmd run dev`) 전달

```text

```

### 🧠 에이전트 실행 전략 (Agent Execution Strategy)
- 사용자가 로컬 웹 브라우저(`http://localhost:5173/`)에서 직접 접속하여 UI를 인터랙티브하게 조작할 수 있도록 Vite 개발 서버를 외부 허용 옵션(`--host`)과 함께 백그라운드 데몬 프로세스로 구동.
- 실행 명령어: `npm.cmd run dev -- --host`
- 포트 5173에서 성공적으로 리스닝 확인 (`ready in 248 ms`).

### 📤 에이전트 2차 응답 요약 (Agent Response 2)
- 접속 URL 안내: `http://localhost:5173/`
- 즉시 검증 가능한 4대 체험 시나리오 제공:
  1. AI 부적절물 자동 숨김 & 관리자 심사 센터 조치 체험
  2. 공지사항 등록 권한(학생 vs 교수/과대) 비교 체험
  3. 공간 간 접근 차단(경영대 학생의 컴공 공간 접근 시 `Tenant Access Denied`) 체험
  4. 1단계/2단계/3단계 모드 스위처 전환 체험
